# Messagerie souveraine de l'administration

Prototype open source de messagerie instantanée sécurisée pour les agents
de l'administration publique burkinabè.
Projet réalisé pour le Sprint technique pré-hackathon 2026 (Hackathon 226).

## Statut

Projet en cours de développement. Ce README sera complété au fil du sprint :
concept, architecture, technologies et licences, installation, limites.

## Architecture envisagée

- Serveur Matrix (Synapse) avec chiffrement de bout en bout
- Client Element
- Keycloak pour l'identité et l'authentification à deux facteurs
- Tableau de bord d'administration en Shiny pour Python
